# MikanRemote

MikanRemote is an app to remote control a mac from an iphone on a very narrow scope. E.g,

- Launch remote browser
- Go to Netflix in remote browser
- Go to YouTube in remote browser
- Move and click mouse on remote Mac (but only on browser - don't allow click on other UI elements)

The use case is very simple. It's for times when I'm on my exercise bike and I want to watch Netflix or YouTube on my Mac on my studio display and controlling it is impossible.
