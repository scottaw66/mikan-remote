## Project Overview

Mikan Remote is an iPhone app that remote-controls a Mac in a narrow scope: launching a browser, navigating to streaming sites (Netflix, YouTube), and moving/clicking the mouse — restricted to browser windows only (no clicking other UI elements). The use case is controlling a Mac from an exercise bike.
